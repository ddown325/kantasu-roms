# Kantasu-Roms

A purple-themed N64 ROM collection web app with in-browser emulation powered by EmulatorJS.

## Features
- 🎮 Play N64 games directly in your browser
- 🟣 Purple-themed UI with OG-Rom and Rom-Hacks tabs
- ⬇️ Download ROMs for use in external emulators
- 📱 Mobile-responsive design with touch controls

## Games

### OG Roms
- Super Mario 64
- The Legend of Zelda: Ocarina of Time
- The Legend of Zelda: Majora's Mask
- Banjo-Kazooie

### Rom Hacks
- Super Mario 64 (Kantasu Edition)

## Tech
- [EmulatorJS](https://emulatorjs.org/) - Browser-based N64 emulation
- mupen64plus_next core
- No build tools - plain HTML/CSS/JS

## Usage
Host on any static web server (GitHub Pages, Netlify, etc.)
